This repository contains an executable replacement application, not just a plan. It is nevertheless an experimental implementation with open feature and release work.

| Delivered | Evidence |
|---|---|
| Python package, CLI, loopback operator service and MCP stdio | Unit/integration/installed-package tests |

| Named procedure activation, editorial checks and evaluation accounting | Pinned registry, Vale/Promptfoo controls and calibration tests |
| Installation, migration, Git-history backup and restore | Fresh prefix, customized-fixture migration and installed-artifact tests |
| Complete requirements, diagrams, CI and installation prompt | All PF01–PF71 retained with current status |

Remaining implementation work is not limited to running tests. The feature register explicitly includes semantic project routing, richer multi-deliverable interpretation, native child/peer ownership conformance, full resource reservations, external-store deletion/retention, broader language packs and provider bridges. The optional backends are not implemented. Do not read a blocked live gate as proof that every underlying feature is finished.

The Mac installation agent should use the committed replacement prompt, qualify the actual configured profile and port local customizations before cutover. No command in this development session accessed or uninstalled Olympus on the user's Mac.

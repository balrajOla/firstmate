# Research

Define the question and scope. Inventory declared sources; record pending, extracted, reviewed, excluded and failed items. Search exact identifiers and conflicting claims. Reopen originals, preserve source dates and capture hashes. Use current authoritative sources for unstable facts when an authorized search tool is available. Otherwise state that fresh web coverage is unavailable. Keep facts separate from inferences. Record citations and unresolved contradictions. Bound fan-out, time, output and model spend. A completed researcher run is not a verified result.
